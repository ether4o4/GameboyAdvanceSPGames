# Static Rush — Watch7

Original round-screen momentum platformer. Gesture mapping: swipe left/right for motion, upward flick or upper-screen tap for jump, center tap to brake. Rendering target 450x450; scale proportionally. Frame-time-based physics, ground collision, collectibles, pause on app background, and persistent high score. Character rides a levitated trash-can lid. No copyrighted assets included.

Implementation: Kotlin Android custom View/Canvas, Wear OS launcher activity, target SDK 35. Test on a real Galaxy Watch7 before release.
